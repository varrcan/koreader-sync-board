# Настройка

[English](../configuration.md) | Русский

Сервер настраивается переменными окружения. `ksb serve` также принимает `-listen` и
`-data-dir`, которые переопределяют окружение.

## Общие

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `KSB_LISTEN` | `:8080` | Адрес для прослушивания |
| `KSB_DATA_DIR` | `/data` | Каталог данных (база SQLite `ksb.sqlite3`, миниатюры обложек в `covers/`, сконвертированные книги в `converted/`, рабочие файлы конвертации в `tmp/`) |
| `KSB_KOSYNC_REGISTRATION` | `false` | Разрешить создание учётных записей из KOReader (`POST /users/create`) |
| `KSB_KOSYNC_SELF_DELETE` | `false` | Разрешить удаление учётной записи с устройства (`DELETE /users/me`) |
| `KSB_TRUSTED_PROXIES` | — | Обратные прокси, чьему `X-Forwarded-For` можно доверять: CIDR или отдельные адреса через запятую (см. [Безопасность](security.md#за-обратным-прокси)) |
| `ADMIN_USER`, `ADMIN_PASSWORD` | — | Создать при первом запуске администратора с паролем панели (только при пустой базе). Задайте обе или ни одной; пароль — не короче 8 символов |

## Библиотека

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `KSB_LIBRARY_SCAN_INTERVAL` | `6h` | Период сканирования библиотеки как Go duration (`30m`, `12h`), не меньше `1m`; `0` — сканировать только при добавлении каталога и по запросу |
| `KSB_GOOGLE_BOOKS_API_KEY` | — | Включает Google Books как каталог метаданных; ключ никогда не пишется в лог |

## OIDC

См. [Вход через OIDC](oidc.md).

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `KSB_OIDC_ISSUER` | — | URL провайдера OIDC; включает OIDC вместе с `KSB_OIDC_CLIENT_ID` и `KSB_PUBLIC_URL` |
| `KSB_OIDC_CLIENT_ID` | — | Client ID у провайдера |
| `KSB_OIDC_CLIENT_SECRET` | — | Секрет клиента; пусто для публичного клиента только с PKCE |
| `KSB_PUBLIC_URL` | — | Публичный origin панели без пути, для redirect URI |
| `KSB_OIDC_NAME` | `SSO` | Подпись кнопки входа: «Войти через …» |
| `KSB_OIDC_SCOPES` | `openid profile email` | Через пробел; `openid` добавляется всегда |
| `KSB_OIDC_USERNAME_CLAIM` | `preferred_username` | Claim для имени автоматически созданного пользователя |
| `KSB_OIDC_AUTO_CREATE` | `false` | Создавать пользователя панели при первом входе неизвестной учётной записи провайдера |
| `KSB_OIDC_ADMIN_CLAIM`, `KSB_OIDC_ADMIN_VALUE` | — | Назначать роль администратора по этому claim ID-токена при каждом входе через OIDC. Задайте обе или ни одной |
| `KSB_PANEL_PASSWORD_LOGIN` | `true` | `false` отключает пароль панели для пользователей, привязанных к OIDC (требует OIDC) |
