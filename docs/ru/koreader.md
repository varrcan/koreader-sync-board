# Подключение KOReader

[English](../koreader.md) | Русский

Сначала добавьте устройство для читалки: в панели в разделе **Устройства** или командой
`ksb device add <пользователь> <устройство>` (см. [Пользователи и устройства](users.md)). Экран
**Справка** в панели показывает те же шаги с уже подставленным адресом вашего сервера.

## Синхронизация прогресса

1. Откройте книгу, затем **вкладка инструментов (гаечный ключ) → Синхронизация прогресса
   чтения → Свой сервер синхронизации** и впишите `http://<хост>:8080`.
2. **Зарегистрироваться / Войти** → введите имя пользователя и **пароль устройства**, затем
   нажмите **Войти**. Регистрация с устройства по умолчанию выключена; см.
   `KSB_KOSYNC_REGISTRATION` в разделе [Настройка](configuration.md).
3. Необязательно, KOReader v2026.07 и новее: включите **Отправить метаданные документа**, чтобы
   сервер получал с каждым обновлением имя файла, название и авторов. Без этого сервер знает
   только хеш документа.

Поддерживаются оба метода сопоставления документов (*Бинарная* и *По имени*).

## Статистика чтения

KOReader отправляет статистику чтения (`statistics.sqlite3`: время и страницы по каждой книге)
через встроенную облачную синхронизацию по WebDAV. Сервер принимает её по адресу `/dav` с тем же
паролем устройства; плагин не нужен.

1. **Облачное хранилище+** → добавьте сервер **WebDAV**: адрес `http://<хост>:8080/dav`, имя
   пользователя и **пароль устройства**. Стартовую папку оставьте пустой. В KOReader 2026.07
   таких пунктов меню два: нужен **Облачное хранилище+**. У старого **Облачного хранилища** свой
   список серверов, и синхронизация статистики его не видит.
2. **Статистика чтения → Настройки → Облачная синхронизация** → выберите этот сервер, затем в
   списке папок нажмите и удерживайте **Долгим касанием здесь выбирается текущая папка**.
3. **Статистика чтения → Синхронизировать немедленно**. Повторяйте, когда нужно: таймера в
   KOReader нет.

Несколько читалок одного пользователя объединяют статистику через сервер: KOReader скачивает
файл, сливает его со своим и выгружает результат. Создатель словаря
(`vocabulary_builder.sqlite3`) синхронизируется так же и хранится как есть. Размер файлов
ограничен 64 МиБ.

- Используйте пароль, выданный панелью или `ksb device add`. KOReader декодирует пароль WebDAV
  как URL, поэтому пароль с `%` (такое возможно, если его задали из KOReader через
  **Зарегистрироваться** или сменой пароля) работает для синхронизации прогресса, но не для
  WebDAV.
- Панель показывает время последней синхронизации статистики и позволяет загрузить
  `statistics.sqlite3` вручную (например, со старой читалки). Загруженный файл сливается со
  статистикой на сервере без удаления данных, и читалки получат результат при следующей
  синхронизации.
- Книги, синхронизированные без **Отправить метаданные документа**, получают название и авторов
  из статистики.

## Каталог OPDS

Если настроена [библиотека](library.md), добавьте каталог в KOReader: вкладка **Поиск** в
файловом менеджере → **Каталог OPDS** → меню в заголовке → **Добавить каталог**, URL
`https://<хост>/opds`, имя пользователя и **пароль устройства**.

## Через интернет

Синхронизация прогресса, WebDAV и OPDS передают пароль устройства в каждом запросе. За пределами
домашней сети ставьте сервер за обратный прокси с TLS: см. [Безопасность](security.md).
